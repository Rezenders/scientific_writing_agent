# Author Writing Preferences

Project-owned preferences, not grammatical rules. Edit this file directly in
either installation mode; installation, update, and plugin regeneration preserve
an existing copy. Explicit task instructions take precedence. Scientific meaning,
technical precision, and grammatical correctness take precedence over preferences.

Suggested defaults (change or remove any item):

- Prefer direct predication when it expresses the same relationship.
- Prefer explicit referents when a demonstrative would otherwise be ambiguous.
- Avoid unnecessary copular indirection and redundant light-verb expressions.
- Prefer concise, technically precise academic English; retain useful complexity.
- Preserve technical terminology and necessary repetition; do not introduce
  stylistic variation solely to avoid repeating a technical noun.
- Semicolons in proposed manuscript prose: allowed. Set this to `avoid` if desired.
  Avoidance is an author preference, never a claim that semicolons are ungrammatical.

Report a preference-based finding as STYLE_PREFERENCE and name the applicable
preference. Do not flag every possible departure; explain its effect in context.
