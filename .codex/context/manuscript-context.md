## Focused Context Files

- `paper-model.md` — repository layout, section map, validation commands, implementation references.
- `style-preferences.md` — optional author preferences, separate from grammatical rules.
- `terminology.md` — canonical terms, acronyms, macros, and forbidden variants.
- `contributions.md` — approved contribution wording and narrative commitments.
- `evaluation-claims.md` — evidence-backed evaluation claims and limits.
- `claim-ledger.md` — high-risk claims with evidence and required qualifications.
- `do-not-say.md` — prohibited overclaims, misleading phrasings, and fragile wording.
- `open-findings.md` — unresolved audit, review, and consistency findings.
- `reviewer-contracts.md` — approved interpretations and response plans for reviewer comments.
- `passage-contract.md` — template for author-approved drafting contracts.

## Operating Rule

Load only the context files needed for the current task. Do not duplicate detailed scientific facts in harness-specific prompts.
